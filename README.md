# ذِكري | ZIKRI

واجهة أولية قابلة للتشغيل لمنصة ZIKRI باستخدام Next.js وTypeScript وTailwind.

## التشغيل
1. ثبّت Node.js 20 أو أحدث.
2. انسخ `.env.example` إلى `.env.local`.
3. نفّذ `npm install` ثم `npm run dev`.
4. افتح http://localhost:3000.

## ما يتضمنه هذا التسليم
- واجهة عربية RTL بهوية زمردية وذهبية متجاوبة.
- أقسام تنقل أساسية، بطاقات القرآن والأذكار والصلاة والقبلة والختمة.
- مسبحة تفاعلية وهدف يومي محليان داخل الواجهة.
- مطالبة تثبيت PWA مع حدث beforeinstallprompt وتعليمات iOS.
- Web App Manifest وأيقونة SVG وService Worker أساسي مع cache versioning.
- لا يتم ادعاء اتصال Supabase أو توفر بيانات قرآن/حديث موثقة.

## ما يحتاج استكمالًا قبل الإنتاج
- ربط Supabase: إنشاء مشروع، إضافة URL وAnon Key، migrations وRLS ومصادقة حقيقية.
- مصدر مرخّص ومراجع لنص القرآن والتفسير والأذكار والحديث والتلاوات.
- خدمة مواقيت صلاة وموقع جغرافي واختبار حساب القبلة والحساسات.
- تحويل الأيقونة إلى PNG بأحجام 192 و512 وApple Touch Icon.
- إضافة صفحات التطبيق ولوحة الإدارة وواجهات API وإدارة البلاغات.
- مراجعة أمنية واختبارات متصفح فعلية ونشر HTTPS.

## إعدادات البيئة
راجع `.env.example`. لا تضع Service Role Key في متغير يبدأ بـ NEXT_PUBLIC.

## تنبيه
هذه نسخة تأسيسية للواجهة وليست منتجًا مكتملًا أو جاهزًا للنشر العام. النصوص الدينية الظاهرة تجريبية ويجب استبدالها ببيانات موثقة قبل الإطلاق.


## Android APK
راجع `ANDROID_BUILD.md`. المشروع مجهز لـ Capacitor وNext.js static export. يتطلب إنشاء APK فعلي تثبيت Android Studio وAndroid SDK ثم تنفيذ خطوات البناء. لم يتم تضمين APK جاهز في هذا الأرشيف.
